# multi
transformer作业
1，transformer为什么抛弃RNN/CNN
    RNN是串行逐个计算，无法并行，长序列梯度容易消失。CNN靠局部窗口，像捕捉远距离信息必须堆叠许多层，而自注意力机制可以多行并行计算，同时可以让任意两个token直接建立关联，长距离信息处理更轻松
2，计算公式以及为什么除根号下d_k
    Attention=softmax[(Q*K_T)/sqrt(d_k)]*V。除d_k是因为d_k越大，点击数值越大，直接送给softmax会饱和，梯度太小无法更新
3，多头注意历史不是单纯的参数多，意义是什么？
    不是，多头注意力是把参数切成多个独立的子参数，每个头学习一个独立的qkv投影，不同的头注意不同的信息关系，最后拼装融合
4，位置编码的必要性，正弦与可学习位置向量区别
    模型不知道语义顺序，所以必须加位置编码。正弦是由固定公式生成，可以外推。可学习位置编码不可外推，上限固定
5，因果掩码mask
    禁止当前位置看到未来的信息，如果不加mask会导致模型能直接看到后面的值属于作弊，会出现过拟合
